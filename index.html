Diccionario Git Interactivo

Tu guía visual y moderna para dominar el flujo de trabajo de ramas y repositorios.

Core 🚀

git init

Inicializa un nuevo repositorio local en la carpeta actual transformándola en un proyecto versionado.

$ git init
Remoto 🌐

git clone

Descarga una copia exacta de un repositorio remoto existente junto con todo su historial de cambios.

$ git clone <url>
Staging 📦

git add

Prepara y añade los cambios realizados al área de espera (staging) para ser incluidos en el próximo commit.

$ git add .
Historial ✍️

git commit

Registra y guarda los cambios preparados (staging) en el historial local del repositorio de manera definitiva.

$ git commit -m "mensaje descriptivo"
